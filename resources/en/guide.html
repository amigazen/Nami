Nami Guide

AmigaOS-specific notes for the Nami fork of NetSurf. Core browsing behaviour matches NetSurf; this guide focuses on what is distinctive aboard this ship.

Window Prefs ARexx Themes CLI about:

Main window

The browser area renders HTML with Hubbub (parser) and LibCSS (style). Images, SVG (via Libsvgtiny), and common formats are handled by the core; the Amiga frontend supplies Intuition/ReAction chrome around that canvas.

Toolbar

Back / Forward
Step through session history. Right-click opens a short menu of recent destinations.
Stop / Reload
In Nami UI style, Stop and Reload share a slot: Stop while a page is loading, Reload otherwise. Shift-Reload forces a full refetch of page elements.
Home
Opens your configured homepage (default about:welcome).
URL bar
Accepts http(s) URLs and Amiga paths such as RAM:index.html. Local volumes are opened as files, not as invented URI schemes.
Search
Uses your default engine from Preferences → Advanced / SearchEngines.

Nami UI style

When UI style is set to Nami, the window drops the system title-bar gadgets and draws an in-layout chrome row: close, tabs, zoom, and depth, with AWeb-style border scrollers for the document. The screen title still reflects the page; dragging the chrome row moves the window.

Note. UI style is frozen when a window is created. Change Preferences, then open a new window to see the other chrome.

Tabs and hotlist

Tabs can appear only when needed, or always (Preferences). The hotlist toolbar is available in classic NetSurf chrome; Nami style keeps the toolbar lean and relies on the Hotlist menu and bookmarks panel.

Preferences

Edit Preferences from the Settings menu. Choices are stored under your user drawer (default PROGDIR:Users/<user>/Choices). Common Amiga-flavoured options include:

Display / Themes
Pick a theme drawer under PROGDIR:Resources/Themes (Default, AISSClassic, AISS, …).
Fonts
Map CSS families to Amiga fonts / TrueType via the font backends compiled into your build.
Cache
Memory and disc cache sizes — keep the disc cache on fast, writable media with the rest of the Users drawer.
Tabs
Always-show tab bar, new-tab behaviour, and related options.

A few options are Choices-file only (for example kiosk mode, printer unit, drag-save icons, monitor aspect). See the AmigaGuide in the distribution for the full list.

ARexx

Nami exposes an ARexx port so scripts can open URLs, control tabs, and automate browsing. Example scripts ship in the distribution Rexx drawer. If Nami is already running, launching it again with a URL typically forwards to the existing instance via ARexx (OPEN / NEWTAB) instead of starting a second copy.

Themes and resources

Bitmaps for toolbar and pointer imagery come from the active theme. Shared documents and engines live under PROGDIR:Resources:

  • en/ — welcome, guide, credits, licence, and this wave-themed CSS
  • en/netsurf/ — archived copies of the previous NetSurf-era HTML pages
  • SearchEngines, ca-bundle, mimetypes, CSS defaults

User overrides can be placed in the current user directory; Nami searches user data, then the theme, then language Resources, then the Resources root.

Command line and tooltypes

Icon tooltypes and shell arguments:

URL
One or more addresses or Amiga files to open.
USERSDIR
Location of the Users drawer (default PROGDIR:Users). Always use fast, non-volatile storage.
USER
Profile name (defaults to the USER environment variable, or Default).

Examples:

  • Nami https://example.com
  • Nami AWeb:Docs/html4_test.html
  • Nami USERSDIR=RAM: RAM:index.html

GNU-style core options may also be passed as --option=value.
